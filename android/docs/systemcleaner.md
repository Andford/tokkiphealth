# Limpiador del sistema

Encuentra basura que no es de una app en particular, con filtros: registros,
temporales, miniaturas, carpetas vacías, APK sobrantes, archivos que dejan
Windows, Mac o Linux al conectar el teléfono, y más.

Tokkip avisa arriba si algo es tuyo: **capturas de pantalla**, la **papelera**
y **tus propios filtros**. Revisa esos antes de borrar.

<a id="settings"></a>
## Ajustes

Cada filtro se prende o se apaga. Algunos tienen opciones (por ejemplo, qué
tan viejas deben ser las capturas).

<a id="custom-filters"></a>
## Tus propios filtros

Crea un filtro para lo que solo tu teléfono junta: elige dónde busca, qué rutas
o nombres coinciden, tamaño y antigüedad. Revisa siempre los resultados antes
de borrar: un filtro mal hecho puede encontrar cosas que sí quieres.
