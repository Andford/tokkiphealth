# Comprimir fotos y videos

Vuelve a guardar tus fotos (JPEG, WebP, HEIC) y videos MP4 para que ocupen
menos. Bajar la calidad es para siempre: mira la comparación antes de empezar.
La fecha, la ubicación y demás datos de la foto se conservan.

<a id="settings"></a>
## Ajustes

Calidad, tamaño y antigüedad mínimos, y qué hacer con fotos HDR, con
profundidad, en movimiento o enormes (por defecto se saltan, para no perder nada).
