# Programar

Limpiezas solas: elige la hora, cada cuántos días y qué herramientas corren.
Las horas son aproximadas porque Android puede moverlas para ahorrar batería.

<a id="additional-options"></a>
## Opciones

- Saltar si no está cargando o con ahorro de energía.
- **Servicio de accesibilidad**: necesita la pantalla desbloqueada. Con Shizuku no hace falta.
- Comandos al terminar, para quien sabe usar la terminal de Android.
