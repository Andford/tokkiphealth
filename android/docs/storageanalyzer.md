# Almacenamiento

Muestra qué ocupa tu espacio: apps, tus archivos (fotos, videos, descargas) y
datos del sistema. Toca para bajar de nivel hasta encontrar lo que más pesa.
Desde ahí puedes borrar o mandar una carpeta a Deslizar.

## Ajustes

Elige cuándo considerar que te queda poco espacio y si quieres un aviso antes
de que se acabe.
