# Duplicados

Encuentra archivos repetidos. Siempre se queda una copia de cada uno: las de
más se pueden ir sin miedo.

- **Copias exactas**: el mismo contenido byte por byte.
- **Parecidos**: fotos, audio o video que se ven o suenan casi igual. Revísalos antes, puede que no sean iguales.

<a id="settings"></a>
## Ajustes

Dónde buscar, tamaño mínimo, cómo se detectan y **cuál se queda** (el más
nuevo, el de la memoria interna, el de tus carpetas preferidas…).
