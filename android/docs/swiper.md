# Deslizar

Para ordenar una carpeta a mano: desliza cada archivo a un lado para
conservarlo y al otro para borrarlo, arriba para saltarlo y abajo para
deshacer. No se borra nada hasta que lo revisas y confirmas al final.

## Ajustes

Invertir las direcciones, ver los detalles del archivo y la vibración.
